Server setup (app owner only)

People who just use AuraStudent never need this page. It is for whoever runs the shared server that delivers alerts and syncs devices. One-time setup, about 15 minutes, free, in your own Cloudflare account. Reminder text and synced data are encrypted on the user's device, so the server only sees delivery times and unreadable blobs.

Step 1. Make your keys

Keys are made in this browser and are not sent anywhere. Keep this page open until the end, or save the two values somewhere private. If you make new keys later, repeat steps 3 and 5.

Step 2. Create a Cloudflare account and the database

  1. Go to dash.cloudflare.com and sign up (free, no card needed).
  2. In the left menu choose Storage & databases, then D1 SQL database, then Create database. Name it aurastudent-push.

Step 3. Create the server

  1. Left menu: Workers & Pages, then Create, then Start with Hello World. Name it aurastudent-push and click Deploy.
  2. Click Edit code. Select all the existing code and delete it. Paste the code below, then click Deploy.

Step 4. Connect the database and the timer

  1. Open your worker, then Settings, then Bindings, then Add, then D1 database. Variable name: DB (capital letters). Choose aurastudent-push. Save.
  2. Settings, then Trigger events (or Triggers), then Cron Triggers, then Add. Enter * * * * * (five stars separated by spaces, meaning every minute). Save.

Step 5. Add the keys

  1. Settings, then Variables and Secrets, then Add. Add these three, then click Deploy:
  2. VAPID_PUBLIC as Text, with the value from Step 1.
  3. VAPID_PRIVATE as Secret, with the value from Step 1.
  4. ALLOWED_ORIGIN as Text, with exactly https://sanjanathogoti21-arch.github.io (no slash at the end).

Step 6. Put the server address in the app

  1. Copy the worker address (ends in .workers.dev). Open it in a browser tab. You should see {"ok":true,"name":"aurastudent-push"}.
  2. In the app's source, set PUSH_SERVER to that address and publish the app. Users then just tap Turn on alerts in Profile. They enter nothing.

Updating the server later

When AuraStudent adds a server feature (for example syncing between devices), copy the server code again from the box above, then open your worker, click Edit code, press Ctrl+A, paste, and click Deploy. Your keys, database and timer stay as they are.

If something fails

  • "Could not reach the AuraStudent server": check the address starts with https:// and opens in a browser.
  • No alert on iPhone: it only works for the app added to the Home Screen, on iOS 16.4 or newer.
  • Alerts late or missing: turn off battery saver for your browser or the installed app, and allow notifications for it.

The free Cloudflare plan (about 100,000 requests a day) comfortably serves tens of daily users. For more, upgrade the plan. Delivery is not guaranteed: it depends on your phone and network.
