Push alerts setup

One-time setup, about 15 minutes, free. You create a tiny server in your own Cloudflare account. It holds your reminder times and sends them to your phone at the right minute, even when AuraStudent is closed. If a screen on Cloudflare looks slightly different from what is described, follow the closest option.

Step 1. Make your keys

Keys are made in this browser and are not sent anywhere. Keep this page open until the end, or save the three values somewhere private. If you make new keys later, repeat steps 3 and 5.

Step 2. Create a Cloudflare account and the database

  1. Go to dash.cloudflare.com and sign up (free, no card needed).
  2. In the left menu choose Storage & databases, then D1 SQL database, then Create database. Name it aurastudent-push.

Step 3. Create the server

  1. Left menu: Workers & Pages, then Create, then Start with Hello World. Name it aurastudent-push and click Deploy.
  2. Click Edit code. Select all the existing code and delete it. Paste the code below, then click Deploy.

Step 4. Connect the database and the timer

  1. Open your worker, then Settings, then Bindings, then Add, then D1 database. Variable name: DB (capital letters). Choose aurastudent-push. Save.
  2. Settings, then Trigger events (or Triggers), then Cron Triggers, then Add. Enter * * * * * (five stars separated by spaces, meaning every minute). Save.

Step 5. Add the keys

  1. Settings, then Variables and Secrets, then Add. Add these four, then click Deploy:
  2. VAPID_PUBLIC as Text, with the value from Step 1.
  3. VAPID_PRIVATE as Secret, with the value from Step 1.
  4. TOKEN as Secret, with the value from Step 1.
  5. ALLOWED_ORIGIN as Text, with exactly https://sanjanathogoti21-arch.github.io (no slash at the end).

Step 6. Connect AuraStudent

  1. On the worker page, copy its address. It ends in .workers.dev. Open it in a browser tab. You should see {"ok":true,"name":"aurastudent-push"}.
  2. Open AuraStudent on your phone (the installed app), go to Profile, find Push alerts that work when the app is closed.
  3. Paste the address and the TOKEN. Tap Turn on push alerts and allow notifications.
  4. Tap Send a test. A notification should arrive within seconds. Do this on every device you want alerts on.
  5. Lock the phone and set a task for a few minutes ahead to try a real alert.

If something fails

  • "Wrong access token": the TOKEN in AuraStudent must match the one in Cloudflare exactly.
  • "Could not reach your push server": check the address starts with https:// and opens in a browser.
  • No alert on iPhone: it only works for the app added to the Home Screen, on iOS 16.4 or newer.
  • Alerts late or missing: turn off battery saver for your browser or the installed app, and allow notifications for it.

Free limits are far above what one person uses. Delivery is not guaranteed: it depends on your phone and network.
